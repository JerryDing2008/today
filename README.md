# 🌱 Today

> Build first. Polish later.

Today 是一个轻量级的数字花园（Digital Garden），用于记录真正属于今天的事情。

与传统任务管理器不同，Today 更关注“现在”。

今天要完成的事留在 Today，
未来的想法放进 Someday，
过去的记录储存在 Archive。

---

## ✨ Features

### ✅ Daily Tasks

记录今天最重要的任务。

每一天都值得重新开始。

---

### 🌱 Someday

保存未来的想法与计划。

暂时不着急，但不想忘记的事情，都可以种在这里。

---

### 📦 Archive

存放过去的记录。

完成的、遗忘的、已经成为回忆的事务都会留在 Archive 中。

---

### ☁️ Cloud Sync

登录账号后自动同步：

- Todos
- Detail Notes
- Someday
- Completed Status

支持电脑与手机无缝切换。

---

### 👤 Account System

支持：

- Sign Up
- Login
- Logout
- Persistent Session

登录后自动保持状态。

## 🎨 Design Philosophy

Today 不是一个企业级任务管理工具。

它更像一座属于自己的数字花园。

```
Today    → 今天
Someday  → 未来
Archive  → 过去
```

希望帮助用户专注于真正重要的事情，而不是被无穷无尽的任务列表追赶。
